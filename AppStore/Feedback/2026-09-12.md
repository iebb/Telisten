## Additional crash and reliability review

The Crash Feedback page contains five reports: random crashing with missing channel songs (build 43), crashing on Next (38), and three iPad reports involving opening a browser, switching apps, and Slide Over (43, iOS 18.4.1).

Confirmed problems and changes:

- On an iPad simulator running iOS 18.4, rotating with the player inspector open and then backgrounding the app produced SIGABRT. UIKit reported a visible navigation bar whose top item belonged to another navigation bar, with a possible nested-navigation-controller conflict. Removed the player/settings inspector path. iPad now presents the player in its own full-screen cover and Settings in its own sheet; presentation no longer switches containers with horizontal size class.
- Queue playback captured an array index in an asynchronous task. Replacing or clearing the queue before the task ran could select the wrong song or index past its end. Capture the selected track before creating the task, cancel superseded playback tasks, and check cancellation after asynchronous preparation.
- End-of-track notifications could already be queued when an item was replaced. They now verify the current AVPlayerItem identity before changing playback state or advancing the queue.
- A failed channel pagination request discarded the remote cursor's availability and silently stopped loading songs. Preserve pagination and show an explicit retry action instead.
- Repeat One intercepted manual Next. Manual Next/Previous now navigate normally; only natural completion repeats the current song.
- Reject non-finite seek values and invalid durations; avoid an integer-conversion trap when formatting extremely large durations.

The queue and pagination findings are confirmed code defects. They are plausible contributors to the reports, but the production crash stacks were not available for attribution. The iPad backgrounding failure was reproduced locally with a UIKit exception in the simulator log.

`Scripts/test-playback.sh` adds regression coverage for stale item completion, normal completion, invalid seek/duration values, and duration formatting. It runs in Apple CI alongside the existing tests. Native WAV checks now have a timeout so a decoder stall fails the check instead of hanging CI.

After the iPad presentation change, repeated rotation, Home/backgrounding, and reopening on iPad Pro 11-inch / iOS 18.4 preserved the same process and player state. The process log contained no navigation assertion or termination. Also verified manual Next with Repeat One and two rapid Next presses (ending on Space Song) without a crash. Both final iOS Simulator and macOS Debug builds pass. Playback regression, WAV, playlist mirror, and offline lyrics checks pass. Live account pagination recovery and production crash attribution remain unverified.
