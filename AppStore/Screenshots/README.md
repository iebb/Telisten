# Screenshot sets

App Store Connect accepts 1–10 screenshots per device class. Keep exported screenshots free of alpha channels and do not add device frames, captions, or decorative marketing elements.

- `iPhone-6.9`: 1320 × 2868 pixels
- `iPad-13`: 2064 × 2752 pixels
- `Mac`: 1280 × 800 pixels

The repository's Debug-only `--demo` launch argument provides deterministic, non-account screenshots. Optional routes are `--demo-chat`, `--demo-playlist`, and `--demo-now-playing`.
